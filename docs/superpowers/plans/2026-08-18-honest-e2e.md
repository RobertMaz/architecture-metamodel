# Честный e2e (подпроект 9) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Полный прогон petclinic всеми полками разом: сорцы + JAR всех модулей + живые приложения (config/discovery/сервисы/gateway) с Actuator + реальные OTel-спаны с трафиком через gateway. Плюс два пробела статики, вскрытых вопросом «почему не все связи»: маршруты Spring Cloud Gateway из yml и multi-document конфиги.

**Spec:** развитие полок config (роуты gateway) и runtime (OTLP JSON-lines, peer.service) из основной спеки.

### Task 1: ConfigLane — маршруты gateway и multi-doc yml
Multi-document application.yml (`---`) читается целиком (первый документ побеждает при конфликте ключей); `spring.cloud.gateway[.server.webflux].routes[]`: `uri: lb://X | http://X` → OUTGOING_CALL{host=X, urlTemplate=uri, route=Path-предикат} conf 0.9. Тесты на фикстуре с multi-doc и обоими путями роутов. Commit.

### Task 2: RuntimeLane — OTLP JSON-lines и peer.service
Файл спанов: строки, каждая может быть OTLP-обёрткой (`{"resourceSpans":[...]}`) — разворачивать; для CLIENT-спанов `peer.service` (если есть) предпочитается host из url (иначе localhost-шум при lb-резолве). Тесты. Commit.

### Task 3: Сборка и запуск стека
`./mvnw package -DskipTests` (все модули), скачать opentelemetry-javaagent; запустить: config 8888, discovery 8761, customers 9101, visits 9102, vets 9103, gateway 9100 (с javaagent: logging-otlp → лог, peer-service-mapping на 9101-9103), admin 9104, genai 9105 (если стартует без ключа); actuator: mappings,env,health. Дождаться health, прогнать трафик через gateway (/api/customer/owners, /api/vet/vets, /api/visit/**, /api/gateway/owners/1). Спаны из лога gateway → workspace файл.

### Task 4: Полный анализ и приёмка
repos.yml: jar всем, runtimeUrl живым, traces gateway'ю; analyze --all; регенерация; новые рёбра gateway→customers/vets/visits/genai (роуты+рантайм) на месте; триаж остатков; `npm run check` 0 ошибок; идемпотентность; погасить апки; повторный прогон с мёртвым рантаймом — байт-в-байт (персистентность). Docs, commit, merge.
