# Экспорт памяти Claude Code

Снимок персистентной памяти Claude Code по этому проекту (снят 2026-08-20).
Здесь накопленный контекст сессий: решения по arch-analyzer, проверенные грабли
LikeC4, бэклоги, ссылки на ресёрч-отчёты. `MEMORY.md` — индекс, остальные файлы —
по одному факту.

## Восстановить на новой машине

Память живёт в `~/.claude/projects/<слаг-пути-проекта>/memory/`, где слаг — это
абсолютный путь к репо с заменой `/` на `-`. Пример для `/home/user/IdeaProjects/architecture`:

```bash
DEST=~/.claude/projects/-home-user-IdeaProjects-architecture/memory
mkdir -p "$DEST"
cp docs/claude-memory/*.md "$DEST"/
rm "$DEST"/README.md
```

Точный слаг проще всего узнать, запустив `claude` в корне репо и посмотрев,
какой каталог появился в `~/.claude/projects/`.

## Замечания

- Снимок отфильтрован для публичного репо: сюда попадают только заметки про этот
  проект; память про другие проекты и рабочий контекст переносится отдельно, руками.
- Это снимок, а не синхронизация: живая память на машине может уйти вперёд.
  Перед переездом обновить снимок: `cp ~/.claude/projects/<слаг>/memory/*.md docs/claude-memory/`.
