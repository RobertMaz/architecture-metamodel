Диагноз 2026-08-19 (подтверждён экспериментами на живом стеке): «диаграммы не обновляются
после анализа до рестарта up.sh» — это НЕ мёртвый вотчер. likec4 на невалидную модель
реагирует молча (держит последнюю валидную, в лог ничего). Волна неатомарных записей
`npm run gen` + отсутствие validate в серверном потоке + гонка дебаунса = тихое застревание.

Отложенный фикс (пользователь: «пока пох, потом посмотрим»): в `Runs.generateModel()`
(1) `likec4 validate` после gen, невалидно → прогон failed; (2) стамп-файл
`model/gen/_stamp.c4` (gitignore) через ~2с после волны как пинок вотчеру.

Детали и смежные грабли (inotify-лимиты, уехавшие порты) — `meta.md`, раздел
«Задел: тихое застревание likec4». См. [[arch-analyzer-project]], [[likec4-view-predicates]].
